# xiaocai-stock-ai · A 股问答引擎

用 Python 引擎回答 A 股问题, 数据来自公开市场(新浪/东财/Tushare), 分析框架自研(BIAS/60 日位置/资金流/事件驱动 vs 资金脉冲), 不靠模型即兴发挥。

## 何时调用

用户问到以下任一类问题, 立即用本 skill:

- **个股**: "中际旭创能上吗" / "宁德时代怎么样" / "被套在茅台了怎么办"
- **板块**: "光通信板块怎么样" / "半导体设备近期走势"
- **选股**: "从半导体设备里选 3 只" / "结合今天热点选 5 只 20 元以内的"
- **选板块**: "给我 3 个明天可以买的细分板块"
- **对比**: "中际旭创和新易盛哪个强" / "比亚迪 vs 长城汽车"
- **行情/大盘**: "今天大盘什么情况" / "创业板走势"

不适用: 港股/美股/加密货币/期货/公司深度研究/宏观经济长文。

## 使用方式

### 前置检查

```bash
python3 -c "from core.engine import answer_fast; print('OK')"
```

如报错, 用户尚未装配依赖, 提示他执行:

```bash
cd ~/.claude/skills/xiaocai-stock-ai   # 或用户 clone 的位置
pip install -r requirements.txt
cp .env.example .env                    # 编辑填 DEEPSEEK_API_KEY 和 TUSHARE_TOKEN
```

### 调用

Skill 目录下有个 `scripts/ask.py` 一行命令拿结果, 你直接 Bash 调用即可:

```bash
python3 scripts/ask.py "中际旭创怎么样"
```

`scripts/ask.py` 自动识别问题类型走最合适路径, 输出结构化文本(结论前置)。

### 追问

如果用户是紧接着上一轮问答的追问(如"那现在能上吗"), 把上一轮的问答摘要传进 --context:

```bash
python3 scripts/ask.py "那现在能上吗" --context "刚才问了中际旭创的走势, bot 说 BIAS20 才 3.72, 可上等回踩"
```

## 输出说明

引擎返回的答案已经是**结论前置的自然语言**, 不需要你二次加工。典型格式:

- 第一句: 明确判断 (能上/别碰/等回踩/够格的只有 N 只)
- 中段: 数据支撑 (BIAS/60 日位置/主力资金/技术形态/估值)
- 结尾: 操作建议 (现价能上? 还是等回踩? 仓位多少? 止损放哪?)

## 硬底线(引擎自带)

- 严禁"买入/卖出/目标价"字眼 (合规底线)
- 出货结构 → 不接飞刀
- 20cm 涨停 → 不追
- ST 股 → 强制警示

## 不确定的情况

- 数据源问题: 引擎会明说"数据不足"或"暂未采集到 XX", 不硬编数字
- 境外主题: 会友好拒绝 (英伟达业绩类, 但英伟达概念股 A 股受益方向可以答)
- 荐股请求: 会引导到"研究参考"定位, 不给"帮你选牛股"
